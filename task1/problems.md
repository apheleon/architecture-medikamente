# Проблемные зоны

| Компонент / Процесс | Текущие меры безопасности | Выявленные проблемные зоны |
| :--- | :--- | :--- |
| **Файловое хранилище (общий диск)** | Доступ через Active directory. | **Критично:** Отсутствует разграничение доступа на уровне папок/файлов. Нет шифрования данных на диске. Нет аудита доступа. |
| **Передача данных по email** | Используется внутренний Exchange. | **Высокий риск:** Результаты анализов передаются в виде вложений. Нет шифрования. |
| **Excel-файлы с PII и медицинскими данными** | Нет. | **Критично:** Данные в открытом виде. Нет паролей на файлы. Невозможно применить политики DLP. |
| **Доступ сотрудников** | Active directory | **Высокий риск:** Администратор ресепшена имеет доступ ко всем медицинским картам. |
| **1С** | Авторизация внутри 1С. | **Средний риск:** Файловый режим работы не предназначен для большого числа пользователей и филиалов. Риск повреждения файлов баз данных. |
| **ККМ** | Интеграция с 1С. | **Низкий риск:** Данные о платежах относительно защищены. |
