#  Список инструментов, способов и мер

## Внедрение EMR(1С:Медицина)
### Что даёт
1. Централизованное хранение: PG
2. RBAC
3. Возможность аудита
4. Единый источник истины для записей, медицинских карт, платежей и анализов.

## Классификация и защита данных
### Данные для защиты
| Категория данных | Примеры | Способ защиты |
| :--- | :--- | :--- |
| **PII** | ФИО, телефон, e-mail | Шифрование на уровне базы данных. Маскирование. |
| **Особо чувствительные** | Диагноз, результаты анализов | Шифрование на уровне приложения/БД. |
| **Медицинские анализы** | Сканы, рентген | Шифрование файлового хранилища. |
| **Финансовые данные** | Сумма платежа | Шифрование в БД. |

### Тегирование данных
Внедрение системы классификации данных (например, метки: Публичные, Конфиденциальные, Персональные данные, Медицинская тайна). Это можно сделать на уровне политик в EMR.

## Технические и организационные меры

1. DLP. Решения для предотвращения утечки данных
2. SIEM. Выявление аномалий: кто-то открыл очень много медицинских карт за еороткоре время.
3. BitLocker для рабочих станций
4. VPN для подключения к сети филиалов, например
5. Обучение сотрудников по работе с PII, документами. Рабочий стол должен быть чист от документов не относящихся к текущему пациенту.
